## Environment

- catalyst-core 1.2.1, built from this repository at commit `55c93f29` (`npm run sync-core`), production build (`catalyst build` + `catalyst serve`)
- Chrome 158.0.8127.37, headless; Lighthouse 13.6.0; Node v22.23.0
- Apple M3 Pro, 11 cores, 18 GB, Darwin 25.2.0
- Server, sprites and browser on one machine (localhost). Collected 2026-11-26.

## Input before hydration, Slow 4G + 4x CPU

5 runs each, list page. Times are medians from navigation start. A run counts only if the action finished before the element it targets had hydrated.

- Typed "pika" into the search box at 685 ms (5 of 5 runs before hydration); the box hydrated at 1,860 ms. After hydration the text was still there in 0 of 5, and the list was filtered to the 1 match in 0 of 5.
- Clicked the first card at 671 ms (5 of 5 runs before hydration). The detail page loaded in 5 of 5, as a full page load in 5.
