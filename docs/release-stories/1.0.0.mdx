<Section eyebrow="02 / What's new" title="Stable, at last.">

<Features>

<Feature title="The API, frozen" image="/img/releases/1.0.0/api.jpg" by="mayansharma" pr="446">

The root entry exports exactly eight names: `RouterDataProvider`, `useCurrentRouteData`, `useRouterData`, `MetaTag`, `split`, `hydrationReady`, `Head` and `Body`. A removed name fails at build time instead of resolving to `undefined`.

</Feature>

<Feature title="Native hooks, one contract" image="/img/releases/1.0.0/hooks.jpg" by="mayansharma" pr="447">

Every native hook uses the same keys: `loading`, `data`, `error`, and `execute` where a hook wraps one operation. The change is additive, and the older names stay as aliases until 2.0.

</Feature>

<Feature title="Every failure has a code" code="RUNTIME-NATIVE-001" by="mayankmahavar1mg" pr="381">

Build, native and runtime errors come from one registry. Each carries a code, a suggested action and a docs link, and hook errors are `CatalystError` values you can compare against `ERROR_CODES`.

</Feature>

</Features>

</Section>

<Section eyebrow="03 / Goodbye, hello">

<Farewell from="export * from 'react-router'" to="react-router@^7.18.2" by="mayansharma" pr="446">

`catalyst-core` no longer re-exports React Router. It is a peer dependency, so import router names from `react-router` directly. The server checks the installed version at startup and exits with a clear error if it is missing or out of range.

</Farewell>

</Section>

<Tip title="Compare codes, not messages.">

1. Import `ERROR_CODES` from `catalyst-core/errors`.
2. Check `error.code === ERROR_CODES.RUNTIME_NATIVE_PERMISSION_DENIED` instead of matching message text, and send people to `error.docUrl`.
