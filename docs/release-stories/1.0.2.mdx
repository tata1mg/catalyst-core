<Section eyebrow="01 / Try it" title="One file and one hook.">

<Snippets>

<Snippet label="config/config.json" note="Then add public/splashscreen.html">

```json
{
  "WEBVIEW_CONFIG": {
    "splashScreen": {
      "backgroundColor": "#ffffff",
      "minDuration": 1200
    }
  }
}
```

</Snippet>

<Snippet label="ProductPage.js" note="Inside WebMcpProvider">

```jsx
import { useTool } from "catalyst-core/webmcp"

useTool({
  name: "add_to_cart",
  description: "Add this product to the cart.",
  inputSchema: { type: "object" },
  execute: async () => addToCart(productId),
})
```

</Snippet>

<Section eyebrow="02 / What's new" title="Fresh in 1.0.2.">

<Features>

<Feature title="Splash screens, animated" image="/img/releases/1.0.2/splash.jpg" by="mayansharma" pr="533">

Ship `public/splashscreen.html` and the native splash image hands over to your page, which stays up until the app's first page has loaded. `minDuration` holds it a little longer, and it is dismissed after 10 seconds regardless.

</Feature>

<Feature title="Your app, ready for agents" image="/img/releases/1.0.2/webmcp.jpg" by="mayankmahavar1mg" pr="475" tag="Experimental">

`useTool()` registers a tool from a component, a route's `tool` field derives one from the route, and `WebMcpProvider` adds `navigate`, `get_current_route` and `get_page_info`. This docs site registers its own, like `search_docs`.

</Feature>

<Feature title="A calmer terminal" image="/img/releases/1.0.2/terminal.jpg" by="mayansharma" pr="535">

Every command prints a short header, one line per step with its timing, and one diagnostic block on failure with the error code, location, hint and docs link. The full bundler output lives behind `--verbose`.

</Feature>

</Features>

</Section>

<Section eyebrow="03 / Goodbye, hello">

<Farewell from="react-helmet-async" to="React 19 <head>" by="astha1905" pr="502">

`MetaTag` no longer depends on `react-helmet-async`. Route metadata from `setMetaData` renders through React 19's own `<head>` support, and head tags no longer outlive their page after client navigation. If your app imported `react-helmet-async` itself, add it to your own dependencies.

</Farewell>

</Section>
